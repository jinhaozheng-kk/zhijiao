# 中高考真题来源索引

更新日期：2026-06-08

## 采集边界

“全网中高考真题”没有单一权威全集，且试题、答案、解析通常涉及版权和转载授权。当前索引按“可追溯、可核验、低合规风险”优先，不直接收录整套试卷正文，不绕过登录、付费、网盘或反爬限制。

可采集内容建议分三层：

1. 元数据：年份、考试、地区、科目、卷型、来源、页面 URL、文件 URL、发布时间、是否官方、授权状态。
2. 合规摘要：题型结构、分值、知识点、能力要求、试题评析、公开作文题等。
3. 原卷内容：仅在来源明确允许转载/下载、取得授权、或用于内部人工审核且不对外分发时入库。

## 来源优先级

| 优先级 | 来源类型 | 处理策略 |
| --- | --- | --- |
| P0 | 教育部、中国教育考试网、省/市教育考试院、教育局官方页面 | 优先采元数据、官方评析、公开附件；若官方提供试卷 PDF，再登记文件 URL 与许可状态。 |
| P1 | 中国教育在线/掌上高考、高考直通车等教育资讯平台 | 采页面索引和跳转 URL；试卷正文需二次版权审核。 |
| P2 | 21 世纪教育网、学科网、笨小虎、自主选拔在线等资源平台 | 采索引、年份、地区、科目；注意登录、付费、下载条款。 |
| P3 | 个人博客、网盘聚合、论坛转存 | 只作为发现线索，不作为可信内容源；不得批量下载或对外再发布。 |

## 后续采集流程

1. 先按 `zhong-gaokao-real-paper-sources.csv` 维护来源清单。
2. 对每个页面抓取标题、发布时间、来源单位、页面 URL、附件 URL、robots/下载限制、版权声明。
3. 标记 `rights_status`：`official_public`、`platform_terms_required`、`unclear`、`high_risk`。
4. 只有 `official_public` 或已获授权内容进入题库原文处理；其他来源只保留索引和人工核验状态。
5. 入库前做去重：按 `exam_stage + year + region + subject + paper_type + source_url` 去重；附件可加 SHA-256。
6. 对题目正文再做结构化解析：题号、题型、分值、题干、选项、答案、解析、知识点、能力层级、图片/公式资源。

## 合规备注

产品侧不要使用“押中原题”“内部题”“考前答案”等表达。真题内容用于教学分析和组卷参考时，应明确来源、年份、地区和版权状态；对外展示优先使用自研变式题、题型结构和知识点映射。
