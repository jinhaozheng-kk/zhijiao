# 初中数学中考风格出卷与打印排版 v1 —— 设计文档

- 日期：2026-06-08
- 状态：待实现
- 背景：AI 出卷已经具备 `Paper` / `PaperItem`、题库优先 + AI 补缺、答案解析、双向细目表、学生卷/教师卷打印版式的基础设计。下一步目标不是“生成真题原题”，而是生成**符合初中数学中考命题风格的原创练习卷**，并让教师打印后可直接发给学生使用。
- 关联：Plan 17 AI 出卷、`2026-06-07-paper-exam-layout-and-structure-design.md`、Plan 13 KP 树、Plan 9 KP reconcile、Plan 3 计费补偿、Plan 6/12 PII 与 owner-only。
- 范围标识：AI 出卷质量增强。首期只覆盖**初中数学通用中考风格**，不扩展到高考、多学科、多地区真题差异。

## 0. 关键决策

1. **产品表达**：对外称“中考风格原创练习卷”，不得称“中考真题”“押题卷”“预测卷”“还原原题”。
2. **目标学科**：v1 只做初中数学，默认覆盖 G7-G9，主场景是 G9 中考复习卷。
3. **卷型**：A4 单栏、题答合一、学生卷/教师卷分离。学生卷不含答案；教师卷同结构穿插答案、解析、评分标准，末尾附双向细目表。
4. **生成方式**：不再让 AI 一次性自由生成整卷。先生成或选定“中考风格命题蓝图”，再按题位逐题生成、校验、组卷。
5. **版式优先级**：浏览器打印/另存 PDF 是 v1 导出路径，但打印页必须按真实试卷渲染，不是普通网页详情页。
6. **版权边界**：公开真题只用于分析题型结构、难度梯度、命题语言和评析，不直接复制题干、答案或解析。

## 1. 目标与范围

教师输入年级、知识点、难度、题量/分值或选择默认模板后，系统生成一份**初中数学中考风格原创练习卷**：

- 命题结构接近通用中考数学卷。
- 题位难度递进，末尾有综合题/压轴题。
- 题干语言克制、准确、无教辅营销味。
- 答案、解析、评分标准可供教师审核。
- 打印学生卷后可直接发放使用。
- 打印教师卷后可直接用于讲评和备课。

### in scope

- 新增“初中数学中考风格模板”。
- 新增“命题蓝图”生成/选用层：题号、题型、分值、KP、能力层级、难度、命题意图、生成约束。
- 按蓝图逐题生成 AI 题；题库有合适题时仍可 best-effort 混入。
- 新增轻量自动审题：结构、合规、重复、题型、难度、答案解析一致性等。
- 打印页升级为 A4 真题卷式渲染器：卷头、密封线、选择题答题区、大题分组、作答空间、分页规则。
- Playwright 打印截图/PDF 验收。

### out of scope

- 直接采集、复制或分发中考真题正文。
- 高考风格、多学科、分省市精细卷型。
- 独立机读答题卡。
- 服务端 DOCX/PDF 导出。
- 几何图自动绘制的高保真编辑器。
- 全量数学符号计算证明；v1 先做规则校验 + AI 自审，后续再接 CAS/几何校验。

## 2. 中考数学模板

新增一个默认模板：`JUNIOR_MATH_ZHONGKAO_GENERIC_V1`。

模板职责：

- 固定大题顺序。
- 固定题型、题量、分值区间。
- 固定难度梯度。
- 约束每个题位的命题意图。
- 给打印页提供卷头与作答区默认规则。

建议默认结构：

| 大题 | 题型 | 题位 | 默认分值 | 难度 | 命题意图 |
| --- | --- | --- | --- | --- | --- |
| 一 | 选择题 | 1-10 | 每题 3 分 | 1-3 | 基础概念、基础计算、图形识别、函数图像、统计概率 |
| 二 | 填空题 | 11-16 | 每题 3 分 | 2-4 | 代数运算、几何性质、函数关系、数据处理 |
| 三 | 解答题 | 17-24 | 6-12 分 | 2-5 | 计算、证明、应用建模、函数综合、几何综合、压轴题 |

v1 允许教师调整题数和分值，但默认模板必须可一键生成。模板生成的 `Paper.paramsJson` 记录：

```jsonc
{
  "styleTemplate": "JUNIOR_MATH_ZHONGKAO_GENERIC_V1",
  "examStage": "ZHONGKAO",
  "subject": "MATH",
  "gradeLevel": "G9",
  "durationMinutes": 120,
  "textbookVersion": "GENERIC",
  "blueprintVersion": "v1",
  "blueprint": [
    {
      "questionNo": 1,
      "type": "SINGLE_CHOICE",
      "points": 3,
      "difficulty": 1,
      "cognitiveLevel": "UNDERSTAND",
      "kpIds": ["..."],
      "intent": "考查基础概念辨析",
      "constraints": ["题干简洁", "只有一个正确答案", "不提示解法"]
    }
  ]
}
```

不新增 DB 表。蓝图作为生成快照进入 `paramsJson`，`PaperItem` 继续存题目快照、分值、难度、能力层级和 KP hints。

## 3. 命题蓝图

新增纯领域结构：`ZhongkaoMathBlueprint`。

每个 `BlueprintSlot` 包含：

- `questionNo`
- `sectionType`：选择题 / 填空题 / 解答题
- `questionType`：映射现有 `QuestionType`
- `points`
- `difficulty`
- `cognitiveLevel`
- `kpIds`
- `kpNames`
- `intent`
- `constraints`
- `answerAreaHint`：`short` / `medium` / `large` / `extraLarge`
- `isCapstone`

蓝图来源：

1. 默认模板确定大题、题位、分值和难度。
2. 根据教师选择的 KP，在题位上做分配，保证主知识点覆盖。
3. 若教师只选少量 KP，则允许围绕这些 KP 生成专题中考风格卷，但卷头标记为“专题练习卷”。
4. 最后 1-2 道解答题标记 `isCapstone=true`，要求综合性、递进小问和较大作答空间。

蓝图必须先于 AI 出题生成，并在预览页展示为“命题结构 / 双向细目表”的一部分。

## 4. 生成流程

现有流程：

`教师参数 → 题库命中 → AI 补缺 → 落 Paper → 打印`

升级为：

`教师参数 → 中考模板 → 命题蓝图 → 题库按题位命中 → AI 逐题补缺 → 自动审题 → 不合格重生 → 落 Paper → 真题卷式打印`

### 4.1 题库混入

题库复用不再只按 `questionTypes + limit` 粗选，而是按蓝图 slot best-effort 匹配：

- subject = 初中数学
- KP 命中
- 题型一致
- 难度接近
- 不重复
- 非 owner-only 私有题

若没有合适题，直接 AI 生成。v1 不要求每个 slot 都必须有题库题。

### 4.2 AI 逐题生成

AI 输入从“生成 N 道题”升级为“按 slot 生成 1 道题”或“小批量同题型 slot 生成”：

```jsonc
{
  "template": "JUNIOR_MATH_ZHONGKAO_GENERIC_V1",
  "slot": {
    "questionNo": 22,
    "sectionType": "解答题",
    "points": 10,
    "difficulty": 4,
    "cognitiveLevel": "ANALYZE",
    "kpNames": ["一次函数", "几何图形"],
    "intent": "考查函数建模与几何关系分析",
    "constraints": ["两问递进", "条件唯一", "不得直接提示解法"]
  },
  "styleRules": [
    "题干使用正式考试语言",
    "避免教辅营销表达",
    "不使用押题、预测、必考等词",
    "解析步骤完整但不冗长"
  ]
}
```

AI 输出沿用现有 `PaperGenerationOutputSchema` 的 item 结构，但调用方以 slot 的 `points/difficulty/cognitiveLevel/type` 为准，不采信 AI 自行调整。

### 4.3 自动审题

新增 `PaperReviewIssue` 结构，不一定落 DB，v1 可作为生成过程内存结果和测试断言：

```ts
type PaperReviewSeverity = "BLOCKER" | "WARNING";
type PaperReviewIssue = {
  slotQuestionNo: number;
  severity: PaperReviewSeverity;
  code: string;
  message: string;
};
```

规则分三类：

**结构校验**
- 题型必须匹配 slot。
- 分值必须匹配 slot。
- 难度不得偏离 slot 超过 1 档。
- 选择题必须有 4 个选项。
- 填空题不得输出选择项。
- 解答题必须有解析；证明题/综合题应有评分标准。

**合规与语言**
- 禁止“押题、预测、必考、提分、包过”等词。
- 题干不得出现“作为 AI”等生成痕迹。
- 题干长度超限时标记 warning。
- 不得出现真实个人信息、学校、考生身份信息。

**数学质量**
- 答案不能为空。
- 解析必须能推出答案。
- 选择题答案必须唯一。
- 同卷题干去重，沿用 `createPaperStemDeduper`，并强化模板去重。
- 若 AI 自审返回“条件不足/答案不唯一/超纲”，作为 BLOCKER。

处理策略：

- `BLOCKER`：该题最多重生 2 次；仍失败则整卷生成失败并触发现有计费补偿。
- `WARNING`：保留题目，但在教师预览页标记“建议人工核对”。
- 生成完成后若 warning 数 > 0，`Paper.status` 仍为 `DRAFT`，提醒教师审核。

## 5. 打印排版

新增或重构打印渲染为考试卷专用组件：

- `ExamPaperRenderer`
- `StudentExamPaper`
- `TeacherExamPaper`
- `ExamHeader`
- `BindingLine`
- `ObjectiveAnswerGrid`
- `ExamSection`
- `AnswerArea`
- `TeacherAnswerBlock`

打印目标：**老师点打印后，不需要再手动调整网页元素即可 A4 使用**。

### 5.1 A4 页面

CSS 要求：

- `@page { size: A4; margin: 16mm 14mm 16mm 18mm; }`
- 打印时隐藏导航、按钮、网页工具栏、toast、调试信息。
- 正文字号建议 10.5pt-11pt。
- 行高 1.5-1.65。
- 标题、卷头、答题表、题目区使用黑白打印友好的边框和文本。
- 不使用大面积底色，避免打印耗墨和灰阶失真。

### 5.2 卷头

学生卷卷头包含：

- 标题：`九年级数学中考风格练习卷` 或教师自定义标题。
- 副行：`满分 X 分 · 考试时间 X 分钟 · 教材版本：通用`。
- 信息栏：`姓名____ 班级____ 考号____ 座位号____`。
- 注意事项：
  1. 答题前请将姓名、班级、考号填写清楚。
  2. 选择题答案填涂在卷头答题表内，其余各题在对应题目下方作答。
  3. 保持卷面整洁，作答写在规定区域内。

教师卷卷头加明显标识：`教师卷 · 含答案解析`。

### 5.3 密封线

打印时左侧显示竖向密封/装订线：

- 文案：`姓名______ 班级______ 考号______  装  订  线  内  不  要  答  题`
- 使用 CSS 竖排或旋转定位。
- 不遮挡题目正文。
- 仅打印视图显示，屏幕预览可弱化。

### 5.4 客观题答题区

卷头下方渲染 `ObjectiveAnswerGrid`：

- 收集所有选择题、多选题题号。
- 每题一行或紧凑网格。
- 单选展示 A/B/C/D 填涂格。
- 多选展示 A/B/C/D/E 等实际选项。
- 学生卷显示空格；教师卷可显示答案或不显示，v1 推荐教师卷在逐题答案块显示，不在答题表提前显示。

### 5.5 大题与小题

沿用 `buildExamLayout` 的大题分组，但增加中考卷式规则：

- 大题标题：`一、选择题（本大题共 10 小题，每小题 3 分，共 30 分）`
- 小题号全卷连续。
- 选择题选项按 2 列或 1 列自适应，避免横向溢出。
- 填空题题后留横线。
- 解答题题下留作答区。

作答区高度由 `answerAreaHint` 决定：

| hint | 用途 | 建议高度 |
| --- | --- | --- |
| short | 填空/短计算 | 18-28mm |
| medium | 普通解答题 | 45-60mm |
| large | 函数/几何综合 | 75-95mm |
| extraLarge | 压轴题 | 105-130mm |

### 5.6 分页规则

- 大题标题不得单独留在页尾。
- 解答题尽量 `break-inside: avoid`。
- 压轴题可强制 `break-before: page`，避免题干和作答区分离。
- 教师卷答案块可以分页，但题干和答案标题尽量同页。
- 学生卷不得泄露答案、解析、评分标准、AI 审题信息。

## 6. 教师审核体验

预览页需要让老师看懂“为什么像中考卷”：

- 显示模板：`初中数学通用中考风格 v1`。
- 显示满分、时长、题型分布、难度分布。
- 显示双向细目表。
- 每题可展开“命题意图 / 对应知识点 / 难度 / 审题提醒”。
- 有 warning 的题标记“建议核对”，不阻止打印，但 `markReady` 前提示。

v1 不要求在线编辑题干，但已有删题/调分值能力不得回退。换题/单题重生可作为后续增强。

## 7. 合规

- 所有模板、prompt、UI 文案不得出现“押中原题、内部题、考前答案、提分保证、通过保证”等表达。
- 生成结果必须是原创题；如果混入题库题，题库题也必须有明确授权或内部来源。
- 对外展示“参考公开考试结构与课标要求”，不展示“来源于某年某地真题”的暗示性措辞，除非只是元数据分析且不含原题正文。
- 教师卷中保留题目来源标记（题库 / AI 生成）供教师核对；学生卷不必显示。

## 8. 测试与验收

### 单元测试

- `buildZhongkaoMathBlueprint`：题位、题型、分值、难度递进、压轴标记正确。
- KP 分配：少量 KP / 多 KP / 空非法输入。
- 自动审题：题型不匹配、选择题多答案、禁词、重复题、缺解析等。
- `AnswerArea`：不同 hint 输出稳定尺寸。
- `ObjectiveAnswerGrid`：题号、选项数量、无选择题边界。

### 集成测试

- `paper.generate` 使用中考模板后，`paramsJson` 含 `styleTemplate` 和 `blueprint`。
- AI 补题按 slot 落 `PaperItem.points/difficulty/cognitiveLevel/type`。
- BLOCKER 触发重生；超过次数后失败且补偿扣费。
- WARNING 不阻止落库，但预览可见。
- 题库题命中 slot 时可混入，AI 只补缺口。
- owner-only、非教师扣费前失败、PII 导出/注销回归不退化。

### E2E / 视觉验收

- 教师生成“初中数学中考风格卷”。
- 预览页显示模板、题型分布、难度分布、细目表。
- 打印学生卷截图：
  - A4 页面不溢出。
  - 无网页导航。
  - 有卷头、信息栏、注意事项、密封线、选择题答题区。
  - 学生卷不含答案。
  - 解答题作答区足够且不明显断裂。
- 打印教师卷截图：
  - 有“教师卷 · 含答案解析”标识。
  - 逐题答案解析可见。
  - 末尾有双向细目表。
- Playwright 至少检查桌面预览和打印截图，必要时保存到 `apps/web/output/playwright/`。

## 9. 风险与取舍

- **像真题但不是真题**：必须通过产品文案和来源标记管理预期。
- **数学严谨性**：v1 不能保证达到人工命题组水平，必须保留教师审核环节；后续可引入符号计算、几何校验和人工题库。
- **打印像素级差异**：浏览器打印可达到“可直接使用”，但不同浏览器/打印机可能有细微差异；服务端 DOCX/PDF 是后续项目。
- **AI 成本上升**：逐题生成 + 审题 + 重生会比一次性生成更贵。v1 可以先小批量按题型生成，再对疑似问题题逐题重生。
- **题库不足**：不阻塞 v1；但要尽早建设授权题库和真题结构元数据库，提升稳定性。

## 10. 后续增强

- 分地区模板：北京、上海、广州、江苏等中考数学卷型差异。
- 单题重生 / 换题 / 改题干 / 调作答区高度。
- 服务端 DOCX / PDF 导出。
- 几何图绘制与图形题模板库。
- 自动难度标定与学生作答数据回流。
- 真题结构分析后台：只存元数据、题型、KP、难度、能力层级，不存未经授权原题正文。
